# Expense Tracker App

A React application for managing expense transactions.

## Features

- View transactions
- Add transactions
- Edit transactions
- Delete transactions
- Search transactions
- Calculate total expenses

## Technologies

- React
- Vite
- JavaScript
- CSS

## Installation

Install dependencies:

npm install

Start the development server:

npm run dev

Build the application:

npm run build

Preview the production build:

npm run preview

## Render Deployment

Build command:

npm install && npm run build

Publish directory:

dist
